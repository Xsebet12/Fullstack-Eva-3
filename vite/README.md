# Frontend (Vite)

**Instrucciones de instalación**
- Requisitos: `Node.js 18+` y `npm`.
- Instalar dependencias:
  - `npm install`

**Instrucciones de ejecución**
- Configurar API base creando `.env` en esta carpeta con:
  - `VITE_API_BASE=http://localhost:8080`
- Desarrollo:
  - `npm run dev`
  - Abrir `http://localhost:5173`
- Compilar para producción:
  - `npm run build`
- Previsualizar compilado:
  - `npm run preview`

Scripts disponibles (`package.json`):
- `dev` — inicia servidor de desarrollo de Vite.
- `build` — genera artefactos de producción.
- `preview` — sirve los artefactos de producción localmente.
- `test` — ejecuta pruebas con `vitest` (si corresponde).
